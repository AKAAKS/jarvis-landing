Privacy

Last updated 12 November 2026

This policy covers the personal assistant software described on this site (JARVIS) and the self-hosted Home Assistant install that shares its Google OAuth client. Both are run by one person — the owner of the Google Account they connect to — on hardware that person owns. There are no other users, no customers and no accounts to create.

What Google data is accessed

The software requests these scopes, and no others:

  • gmail.readonly — searching and reading the owner's own mail, so the assistant can answer questions about it.
  • gmail.compose — creating drafts. It cannot send mail. The send scope is deliberately not requested, so sending is impossible rather than merely disallowed.
  • calendar — reading, creating and deleting the owner's own calendar events.

Where it goes

  • The software runs as a daemon on the owner's own PC. Google data is fetched directly from Google to that machine.
  • When the owner asks a question that requires it, the relevant message or event content is sent to Anthropic's API as part of the prompt, because the assistant is built on a language model. This is the one place data leaves the machine. Anthropic's handling is governed by their own terms.
  • Conversation history and assistant state are stored in a local SQLite file on that PC. The OAuth token is stored in a local file on that PC.
  • Nothing is sold, shared, rented or transferred to any other party. There is no analytics, no tracking, no advertising and no server operated by this project that receives Google data.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be withdrawn at any time from Google Account permissions, which immediately and permanently invalidates the software's credentials. Local data is removed by deleting the stored token and database files from the machine. Because everything lives on hardware the owner controls, there is no copy elsewhere to request the deletion of.

Contact

Questions about this policy go to the support address shown on the Google consent screen for this application.
